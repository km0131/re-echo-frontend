## ステップ F3-1：ギャラリー・写真投稿・写真管理

```
backend の B3-1 に合わせて、docs/design.md の3.5章と4章（写真投稿、写真管理）の画面を作ってください。

やること：
1. /e/:slug/gallery：2列のポラロイドグリッド、FilterChip、処理中の表示、BottomBar（あと◯枚）。一覧はサムネイルだけ（loading="lazy"）。members 画像の URL には ?gate= を付ける
2. 拡大モーダル：表示用サイズはここで初めて読み込む。左右スワイプ、キャプション・投稿者名、「非表示にしてほしい」（理由を1行入力できる確認ダイアログ）、自分の投稿なら「削除」。Esc とブラウザの戻るで閉じる
3. /e/:slug/gallery/upload：複数選択、ポラロイド風サムネイルとキャプション入力、送信中の進捗、「位置情報は自動で消えます」。未回答の人は回答フォームへ誘導
4. 処理中の写真は数秒おきに状態を取り直し、完了したら差し替える
5. 管理画面の「写真」タブ（承認待ち件数バッジ）：フィルタ、承認・却下、公開範囲（public／members／draft）、非表示依頼の対応、ドラッグで並び替え。public にするときは「顔が写っていない写真だけにしてください」と確認
6. イベントトップの「あの頃の写真を見る」リンク、回答完了の「写真をもっと見る」ボタン

完了条件：
1. スマホ実機（make ip で出たURL）から複数枚上げて、処理中→承認待ち→承認→ギャラリーに出る、まで通る（私が確認する手順を書く）
2. 非表示依頼を押すとすぐ一覧から消え、管理画面の「非表示依頼」に出る
3. ギャラリーの幅390pxスクリーンショットを design.md と見比べた報告
```

## ステップ F3-2：ランダムヘッダーと回答完了の演出

```
写真を使った演出を入れてください。

やること：
1. イベントトップのヘッダー：members 写真からアクセスごとにランダム1枚。design.md 3.2 のオーバーレイと、CSS でセピア調・うっすらフィルムノイズ（SVG の feTurbulence を data URI で）を重ねる。写真がなければ photo 色の下地
2. 合言葉ゲートのポラロイドに public 写真（publicPhotoUrl）
3. 回答完了画面（design.md 3.4）：
   - canvas-confetti で紙吹雪（色は yes・kraft・maybe・navy のみ、1回だけ、控えめに）
   - members 写真からランダム3枚を重なったポラロイドで表示（傾き・テープは design.md のとおり）
   - prefers-reduced-motion なら紙吹雪を出さず、傾きのアニメーションもしない
4. 写真の読み込み中は photo 色の下地を出し、読み込めたらふわっと表示

完了条件：
1. リロードするたびにヘッダー写真が変わる
2. OS の「視差効果を減らす」をオンにすると紙吹雪が出ない
3. make preview の状態で Lighthouse モバイルの Performance が 80 以上
```

## ステップ F3-3：OGP（Pages Functions）

```
backend の B3-2 に合わせて、LINE に共有URLを貼ったときにカードが出るようにしてください。

やること：
1. functions/e/[[path]].ts：/e/* へのリクエストで index.html を取得し、HTMLRewriter で og:title、og:description、og:image（ogImageUrl）、og:url、twitter:card を差し込む
2. イベント情報は環境変数 API_ORIGIN の GET /api/v1/public/events/{slug} から取得（Cloudflare のキャッシュを使う）
3. API に届かないときは差し込みなしの index.html を返す（ページ表示を止めない）
4. og:description は「クラスのみんなで日程を決めています。合言葉を入れて回答してね」
5. wrangler を devDependencies に入れ、make preview で Functions ごと確認できるようにする

完了条件：
1. make preview で /e/{slug} の HTML に og タグが入っている（curl で見せる）
2. 参加者の名前やコメントが HTML に一切含まれない
3. 本番で LINE に貼ったときの確認手順（私が行う）
```

## ステップ F3-4：リアルタイム更新

```
backend の B3-3 に合わせて、SSE で画面を自動更新してください。

やること：
1. イベントトップで EventSource（/events/{slug}/stream?gate=…）を開き、changed を受けたら TanStack Query の該当クエリを invalidate
2. タブが非表示の間は切断し、表示に戻ったら再接続して取り直す。切れたら自動で再接続
3. 新しい回答が入ったとき、マトリクス表の該当列をふわっと強調（reduced-motion では無し）
4. proxy モード（Vite 経由）と direct モードの両方で動くことを確認

完了条件：
1. ブラウザを2つ並べ、片方で回答するともう片方の表が数秒以内に更新される
2. backend を再起動しても、数秒後に自動で再接続する
```
