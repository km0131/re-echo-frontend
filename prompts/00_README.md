# ステップ別プロンプトの使い方

このファイルは `backend` と `frontend` の両方のリポジトリに同じものを置いています。

## 準備（最初の1回だけ）

1. 2つのリポジトリ `backend/` と `frontend/` に、それぞれの指示書（`CLAUDE.md`、`docs/`、`prompts/`）を置く。
2. Docker Desktop（Windows は WSL2 版）を入れておく。
3. Claude Code は**リポジトリごとに別々に**起動する（`backend/` で起動した Claude にはバックエンドのステップだけ、`frontend/` の Claude にはフロントのステップだけを貼る）。

## 進め方

- 下の進行表の順に、1ステップずつコピーして貼り付ける。
- 1ステップごとに、AIの報告（完了条件のチェック結果）を確認し、自分でも動かしてから git commit する。
- backend の報告に「フロントへの連絡事項」があったら、backend の `docs/spec.md` を frontend の `docs/spec.md` にコピーしてから、フロントのステップに進む。
- frontend の報告に「バックエンドへの依頼事項」があったら、backend 側の Claude に伝える。
- 会話が長くなったら `/clear` してから次のステップを貼る（`CLAUDE.md` と docs があるので文脈は失われない）。

## ローカルでの動作確認のしかた

```bash
# ターミナル1（backend）
cd backend && make up        # http://localhost:8080
make seed                    # B1-6 以降。サンプルのイベントができる

# ターミナル2（frontend）
cd frontend && make up       # http://localhost:5173
```
