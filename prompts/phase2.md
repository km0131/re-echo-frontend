# フロントエンド フェーズ2：便利機能

各ステップは、backend の同じ番号のステップ（B2-◯）が終わってから進めてください。

---

## ステップ F2-1：ベスト日程・日程確定・カウントダウン

```
backend の B2-1 で追加された best・score・confirmed を画面に反映してください。docs/spec.md は backend からコピーした最新版に更新済みです。

やること：
1. イベントトップに「確定カード」と「いい感じの日」（design.md 3.2 の 3・4）。確定後は「いい感じの日」を隠す
2. マトリクス表でベスト1位の行をハイライト
3. 管理画面の設定タブに「日程を決める」（design.md 3.8）。確定済みなら「決定を取り消す」
4. ダッシュボードの確定カード表示（「1/3（日）18:00〜 ・ あと67日」）

完了条件：
1. 確定するとトップが確定カードに切り替わり、取り消すと戻る
2. 回答0件のとき「いい感じの日」が出ない
3. 幅390pxのスクリーンショットを design.md と見比べた報告
```

## ステップ F2-2：PIN と別端末からの編集

```
backend の B2-2 に合わせて、PIN と別端末からの編集を作ってください。

やること：
1. 回答フォームに PinInput（design.md 3.3 の 8）。既存回答の編集時は「変更する場合のみ入力」
2. /e/:slug/edit（design.md 4章）：名前の選択（hasPin が true の人だけ選べる）＋PIN → 成功したら editToken を保存して回答フォームへ
3. 回答フォームの名前重複エラーに「別のスマホで回答した場合はこちら」リンク
4. ロック中・PIN未設定のエラー表示

完了条件：
1. ブラウザAで回答→ブラウザBで名前＋PINから編集できる
2. 5回間違えるとロックのメッセージが出る
```

---

## ステップ F2-3：追加アンケート

```
backend の B2-3 に合わせて、追加アンケートの画面を作ってください。

やること：
1. 回答フォームに設問を表示（single と multi は Pill、text は1行入力）。design.md 3.3 の 6。任意回答
2. 管理画面の「アンケート」タブ：設問の追加・並べ替え・削除、選択肢の編集、集計（選択肢ごとの人数を細い横棒で。色は yes の1色）、text の回答一覧
3. 新規イベント作成とアンケートタブに、テンプレートをワンタップで追加するボタン：「予算（〜3,000円／〜5,000円／〜8,000円／おまかせ）」「二次会（行きたい／その場で決める／一次会だけ）」

完了条件：
1. 設問を作って回答し、管理画面で集計が見える
2. 回答フォームのスクリーンショットを design.md 3.3 と見比べた報告
```

---

## ステップ F2-4：LINE共有とデプロイ

```
backend の B2-4 に合わせて、LINE共有テキストのコピーを入れ、フェーズ2を本番に出してください。

やること：
1. 管理画面の「URLをコピー」を「LINE用の文をコピー」に変更（share-text を取得してコピー）。コピー後2秒「コピーしました」
2. ダッシュボードの回答率バー（class_size が設定されているときだけ）
3. フェーズ2の全画面を幅390pxと360pxで撮り、design.md と見比べて違いを直す
4. make preview で確認してから本番にデプロイ

完了条件：
1. コピーしたテキストを LINE に貼ったときに崩れない（私が確認する）
2. 本番で PIN 編集、アンケート、日程確定が動く
```
